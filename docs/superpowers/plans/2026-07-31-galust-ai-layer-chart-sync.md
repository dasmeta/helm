# Galust AI Layer Chart Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sync `charts/galust-ai-layer` to current `ai-layer/*/helm` production-shaped values (drop mcpUseCase, add orchestratorScheduler, refresh env/ingress), and document the umbrella as canonical.

**Architecture:** In-place update of the existing umbrella chart: one TrueCharts `strapi` alias (`backend`) plus aliased `dasmeta/base` charts per service. Values and README are the deliverable; CI cutover is out of scope.

**Tech Stack:** Helm 3, `dasmeta/base` 0.3.30, TrueCharts `strapi` 18.9.0, YAML anchors in `values.yaml`

## Global Constraints

- Source of truth for sync: `ai-layer/*/helm` values + ingress YAMLs (not docker-compose)
- Do not copy plaintext secrets from `ai-layer/backend/helm/strapi.yaml` into the chart
- Do not add `productsOpenapiServer`
- Do not rewire CI/CD
- Chart version bump to `0.2.0`
- Repos involved: `dasmeta/helm` (primary) and `dasmeta/ai-layer` (README note only)

## File map

| File | Responsibility |
| --- | --- |
| `charts/galust-ai-layer/Chart.yaml` | Dependencies + version |
